# hello

The smallest plugin, kept as the reference example for building one.

## Screens

- **Hello** (route `/`): a heading "Hello" and one line of text from the
  server function `greeting.get`. "Asking the server…" while it loads; the
  error text below it if the call fails. Plain Tokamak text styles (`text-read`
  for the heading, `text-row` `text-ink-2` for the line), 32 px padding.

No Paper page: this is an example, not a product screen.

## If you change X, check Y

Nothing depends on `hello`.
